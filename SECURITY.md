# Security Policy

## Supported Versions

There are no tagged releases yet. Security fixes, when available, are made on
the `main` branch; no older revision is promised support.

## Reporting a Vulnerability

Do not report security vulnerabilities in public issues or discussions. Use
GitHub's private vulnerability reporting from the repository Security tab
when the **Report a vulnerability** option is available. Repository private
vulnerability reporting was disabled when this policy was written, so
maintainers must enable it before this repository has a working private
reporting route. Until then, do not disclose vulnerability details publicly.

Please include the affected commit or version, impact, and a minimal
reproduction where possible. Do not include credentials or real user Vault
data. The maintainer will acknowledge reports when available; there is no
guaranteed response or remediation time.
