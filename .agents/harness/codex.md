# Codex harness

Use the repository working directory for terminal and file tools. Follow the project instructions discovered through `AGENTS.md`. Verify workspace changes with `cargo xtask check` and report the checks that actually ran.

For documentation or release changes, consult `docs/README.md`,
`docs/licensing.md`, and the matching registered workflow. Do not treat
package validation or a dry-run as proof that third-party material is license
compatible; inspect its source and notices as documented in the release
workflow.

Before accepting externally supplied material, follow
`CONTRIBUTING.md` and `.agents/workflows/contribution.md`.
